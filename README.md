# iximiuz Labs content template

Use this repository as a template for building your own content.

## Usage

1. Create a new repository from this template.
1. Add a new content to the repository.
1. If necessary, create a Docker Bake definition in `.bake`.
1. Add the content to `.github/workflows/e2e.yaml`
